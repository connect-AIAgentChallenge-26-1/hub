# fiTArchive Prototype

데일리룩 사진과 짧은 메모를 함께 기록하는 패션 아카이브 서비스 프로토타입입니다.

## 프로토타입 실행 방법

```bash
npm install
npm run dev
```

## 프로토타입 주요 기능

- 홈 화면의 월별 달력 UI
- 기록이 있는 날짜의 컬러 표시
- 데일리룩 사진 업로드 UI
- look name, memo 입력
- AI color 자동 감지 UI
- 색상 추가, 삭제, 수정
- 기존 기록 수정
- FitCheck 리포트 화면

# fiTArchive

## 문서

- [fiTArchive 기획서](https://github.com/fine1031/fiTArchive/wiki/Planning)

## 프로젝트 소개

fiTArchive는 사용자가 매일 입은 코디를 사진과 태그로 기록하는 개인 패션 아카이브 서비스입니다.

코디를 단순히 저장하는 것에서 끝나지 않고, 일정 개수 이상의 기록이 쌓이면 사용자의 색감, 무드, 상황별 스타일 패턴을 분석해 나만의 취향 리포트를 제공합니다.

## 기획 배경

사람마다 코디를 바라보는 기준과 취향은 다릅니다. 그래서 하나의 코디를 보고 "좋다", "나쁘다"처럼 평가하는 방식은 사용자에게 맞지 않을 수 있습니다.

fiTArchive는 코디에 점수를 매기기보다, 사용자가 직접 쌓아온 기록을 바탕으로 자신의 스타일을 돌아볼 수 있도록 돕는 것을 목표로 합니다.

예를 들어 사용자는 이런 질문에 답을 얻을 수 있습니다.

- 나는 어떤 색상의 옷을 자주 입을까?
- 어떤 무드의 코디를 선호할까?
- 만족도가 높았던 코디에는 어떤 공통점이 있을까?
- 최근 내 스타일은 어떤 방향으로 바뀌고 있을까?

## 주요 기능

### 1. 코디 기록

사용자는 오늘 입은 코디 사진을 업로드하고, 날짜와 함께 다양한 정보를 기록할 수 있습니다.

- 사진
- 날짜
- 상황: 등교, 발표, 약속, 여행, 알바 등
- 무드: 미니멀, 캐주얼, 스트릿, 포멀 등
- 색상 태그
- 만족도
- 메모

### 2. 코디 아카이브

기록한 코디를 카드 형태로 모아보고, 원하는 조건으로 다시 찾아볼 수 있습니다.

- 날짜별 보기
- 무드별 필터
- 상황별 필터
- 색상 태그 검색
- 만족도 높은 코디 모아보기

### 3. FitCheck 리포트

코디 기록이 5장 이상 쌓이면 FitCheck 기능을 통해 사용자의 스타일 패턴을 분석합니다.

FitCheck는 코디를 단정적으로 평가하지 않고, 누적된 기록을 기반으로 사용자의 취향을 리포트 형식으로 정리합니다.

- 자주 입는 대표 색상
- 자주 선택한 무드
- 자주 기록한 상황
- 만족도가 높은 코디의 공통점
- 최근 코디 경향
- 새로운 스타일 시도 제안

## 핵심 가치

fiTArchive는 정답을 알려주는 패션 평가 서비스가 아닙니다.

사용자가 직접 기록한 코디 데이터를 바탕으로 자신의 취향을 발견하고, 더 다양한 스타일을 시도할 수 있도록 돕는 개인 패션 기록 서비스입니다.
