화면 1 · 기능 1

계약 입력

앱을 처음 켰을 때 만나는 화면. 계약 시작일·만료일·보증금만 입력하면 일정이 자동 계산돼요.

  • 전세·월세·반전세 구분 없이 동일하게 입력
  • 보증금 입력 시 천 단위 콤마 자동 표시
  • "만료일 > 시작일" 검증
계약 정보 입력 1 / 1 단계

계약서에 적힌 날짜와 보증금을 입력하면 챙겨야 할 일정이 자동으로 만들어져요. 전세·월세·반전세 모두 같은 방식으로 입력하면 돼요.
