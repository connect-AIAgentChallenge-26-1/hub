# Later — 저장에서 재발견까지 이어지는 AI 콘텐츠 인박스

> 저장은 끝이 아니라, 다시 쓰기 위한 시작이어야 합니다.

## 한 줄 소개

Later는 인터넷과 SNS에서 발견한 URL·텍스트·이미지 꿀팁을 저장하면 AI가 핵심을
한국어로 요약·분류해, 정보 과잉 속에서도 필요할 때 다시 꺼내 보게 만드는 콘텐츠
인박스입니다.

## 문제와 해결

유용한 정보는 브라우저 북마크, 메신저, SNS 저장함과 스크린샷에 흩어집니다. 정보가
쌓일수록 무엇을 왜 저장했는지 잊고, 긴 원문을 다시 읽는 부담 때문에 결국 열어보지
않습니다. Later는 저장 입력을 하나로 모으고, 저장 순간에 제목·핵심 요약·카테고리를
생성해 재발견 비용을 낮춥니다.

## 핵심 경험

1. URL·텍스트·JPEG·PNG·WebP 이미지를 같은 흐름에서 저장합니다.
2. Gemini가 URL Context, 웹 메타데이터와 이미지 맥락을 분석해 한국어 핵심 요약을 만듭니다.
3. 대·소분류, 통합 검색과 필터로 원하는 정보를 빠르게 찾습니다.
4. 카드에서 요약과 원문을 확인하고 다 본 항목은 스와이프로 아카이브합니다.
5. YouTube·Instagram·X 등의 출처를 회색 아이콘과 사이트명으로 명확히 표시합니다.

## 기술적 신뢰성

- Gemini Structured Output과 별도 런타임 검증을 함께 사용합니다.
- AI가 실패해도 규칙 기반 분류로 저장 흐름을 유지합니다.
- URL 수집에 사설 IP 차단, redirect 재검증, timeout, 응답 크기와 형식 제한을 적용합니다.
- 콘텐츠와 이미지 파일은 Supabase Database와 Storage에 분리 저장합니다.
- Instagram Reel처럼 플랫폼이 영상 원문을 공개하지 않으면 캡션 수준까지만 분석하며,
  로그인 우회나 비공개 콘텐츠 수집은 하지 않습니다.

## 현재 범위와 로드맵

현재 운영 버전은 저장·AI 분석·검색·분류·아카이브·PWA 설치까지 제공합니다. 리마인더
알림, 공유 시트, 사용자 로그인과 데이터 격리는 온보딩 시안 및 후속 로드맵입니다.

## AI와 함께 개발한 방식

사람이 문제, UX와 완료 기준을 결정하고 Codex가 코드베이스 분석, 구현, 테스트와
문서화를 수행했습니다. 실제 URL과 이미지를 저장해 결과를 관찰하고, 장황한 소개문
요약이나 플랫폼 원문 접근 제한 같은 실패 사례를 프롬프트·검증·테스트 기준으로 다시
반영했습니다.
