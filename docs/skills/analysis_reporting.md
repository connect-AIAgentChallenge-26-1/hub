# Analysis Reporting Skill

## Purpose

기획 변경의 영향, confidence, 추천안을 근거와 함께 보고한다.

## Impact Types

- NPC
- Quest
- Item
- Dialogue
- UI
- Resource
- Task

## Confidence

- `high`: 직접 근거가 있고 관련 확정 문서가 일치한다.
- `medium`: 일부 직접 근거가 있지만 누락 정보나 미승인 자료가 있다.
- `low`: 근거가 부족하거나 서로 충돌해 사용자 확인이 필요하다.

confidence에는 등급만 쓰지 않고 근거 파일과 낮아진 이유를 함께 기록한다.

## Recommendation

추천안은 다음을 포함한다.

- 제안 내용
- 근거
- 장점
- 단점
- 영향 범위
- 추가 확인 사항

추천은 확정 결정과 구분하고 사용자가 선택하지 않은 안을 적용하지 않는다.
