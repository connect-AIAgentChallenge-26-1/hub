# 완료 증거 Archive

이 디렉터리는 종료된 Work Record, 과거 Troubleshooting·Experiment와 폐기된 Runbook의
상세 실행 증거를 보존한다. 현재 Task 상태나 실행 절차의 정본이 아니며 새 작업은 이곳에
추가하지 않는다.

- `work-records/`: 완료된 WI와 이전 백로그 작성 기록
- `troubleshooting/`: 해결된 환경·Provider 장애 기록
- `experiments/`: 종료된 측정 캠페인
- `runbooks/`: 더 이상 실행하지 않는 절차

현재 계약과 결정은 상위 [문서 인덱스](../README.md)를 따른다. 과거 Linked Live 결과의
사용자 여정 해석은 [CASE-0002](../case-studies/CASE-0002-naver-elice-linked-live-user-flow.md)가
정본이다. Archive 문서는 당시 사실을 보존하므로 현재 명령·경로와 다를 수 있다.
