# 개발 체크리스트

이 문서는 GamePM Codex Workspace의 기능 개발 단위와 진행 상태를 관리한다.
운영 중 반복 점검표가 아니라, `docs/plan.md`의 요구 기능이 실제 규칙과
산출물로 구현됐는지 추적하는 개발 문서다.

## 0. 제품 구조 전환

- [x] API/CLI 실행 제품을 Codex 기반 Markdown 작업장으로 전환한다.
- [x] 서버, 웹 UI, 외부 도구 자동 연동을 제외 범위로 정리한다.
- [x] `AGENTS.md`에 Human in the Loop와 승인 경계를 정의한다.
- [x] workflow, skill, template, workspace 디렉터리를 구성한다.
- [x] `docs/dev-log/`를 현재 동작 근거에서 제외한다.
- [x] `docs/plan.md`를 현재 제품 구조와 목표 기능 기준으로 재작성한다.
- [x] 이 체크리스트를 기능 개발 진행표로 재구성한다.

- [x] 출처 표기 공통 규칙을 workflow와 template에 적용한다.

### 1.5 프로젝트 검색
