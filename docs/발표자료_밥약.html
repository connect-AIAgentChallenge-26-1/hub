문제 정의

밥약 하나 잡는 데
왜 이렇게 오래 걸릴까?

수업 시간표는 에타에, 개인 일정은 구글에, 동아리 일정은 또 다른 곳에.
친구 3~4명과 약속을 잡으려면 이 대화가 무한 반복됩니다:

"언제 시간 돼?" "난 화요일 빼고 다 돼" "어? 나 화요일만 되는데" "그럼 어디서 먹을까…"
시간 맞추기 + 장소 정하기 = 두 가지 낭비를 한 번에 자동화

주요 기능 ①

캘린더 3종 연동 — 구현 완료

흩어진 일정을 하나의 통합 캘린더로. 세 가지 모두 실계정으로 검증했습니다.

GOOGLE 구글 캘린더

OAuth 로그인과 캘린더 읽기 권한을 한 번의 동의로 동시에 획득

EVERYTIME 에타 시간표

공유 링크만 붙여넣으면 주간 시간표를 실제 일정으로 자동 확장

APPLE 애플 캘린더

iCloud CalDAV + 앱 암호로 아이폰 일정까지 통합

주요 기능 ②

모두의 빈 시간을 찾는 법

참여자별 일정 시간순 정렬 → 전원의 "바쁜 시간" 합집합 → 활동 시간의 나머지 = 공통 공강

최소 1시간 이상 이어지는 구간만 후보로 제시

맛집 추천 네이버 + 카카오 병합

두 API의 리뷰 수·평점을 정규화한 통합 점수로 정렬, 상위 3~4곳만 노출

위치 GPS 또는 학교 이름

위치 허용 시 자동, 미허용 시 학교 이름 입력으로 좌표 변환

가볍게, 그러나 확장 가능하게
