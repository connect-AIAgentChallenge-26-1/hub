# 프로젝트 방향 전환 기록

## 현재 목표

프로젝트의 중심을 사람의 상태를 분류하는 기능에서 로봇 자체의 내부 상태가 형성되고
행동에 영향을 주는 시스템으로 전환했습니다.

현재 모델은 예측 오차, 자원 압력, 목표 충돌, 연속성, 상호작용 동기화, 탐색 동력의 여섯
차원을 사용합니다. 입력은 이 차원에 직접 값을 대입하지 않고 제한된 기계 요인으로
변환됩니다. 상태는 시간에 따라 기준값으로 감쇠하고, 갱신 결과가 행동 후보 점수에
반영됩니다.

## 제거한 범위

- 사람 감정 분류와 점수 정규화
- 공감 반응을 위한 키워드 규칙
- 얼굴·목소리 라벨 선택
- 카메라 기반 표정 해석
- 분석 결과 카드와 재분석 흐름
- 기존 분석 API와 저장소의 런타임 연결

## 보존한 범위

기존 DB 데이터와 이미 실행됐을 수 있는 마이그레이션은 복구 가능성을 위해 삭제하지
않습니다. 현재 런타임과 신규 스키마는 해당 테이블을 참조하지 않습니다.

실제 생성형 AI API는 계속 제외하며, 응답은 선택 행동별 템플릿으로 생성합니다.
