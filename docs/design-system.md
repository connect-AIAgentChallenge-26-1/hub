# 디자인 시스템

## 디자인 방향

이 서비스는 네이버지도처럼 지도 자체가 메인 화면이어야 한다. 사용자는 지도에서 식당 같은 업체를 누르고, 하단 또는 우측 업체 상세 시트에서 기본 정보와 인증 리뷰를 확인한 뒤 리뷰를 작성한다. 예약은 주된 서비스가 아니므로 화면 우선순위에서 제외한다.

전체 톤은 iOS 기본 앱처럼 깨끗하고 가볍게 만든다. 반투명 시트, 부드러운 그림자, 충분한 여백, 선명한 텍스트 대비를 사용하되 장식은 줄인다.

## 키워드

- 지도 우선
- 네이버지도형 업체 상세
- 영수증 인증 리뷰
- iOS 클린 UI
- 빠른 비교
- 모바일 우선

## 타이포그래피

- 기본 폰트: system UI, Pretendard 후보
- 업체명: 25~30px, 800 이상
- 섹션 제목: 17~19px, 800
- 본문: 14~16px, 400~600
- 보조 정보: 12~13px, 650~750
- 글자 간격은 기본값을 사용한다.

## 레이아웃

- 첫 화면은 지도다. 랜딩 페이지나 설명형 hero를 만들지 않는다.
- 검색창과 카테고리 필터는 지도 위에 떠 있는 iOS 스타일 컨트롤로 배치한다.
- 업체 선택 시 모바일에서는 하단 시트, 데스크톱에서는 우측 시트를 사용한다.
- 상세 시트에는 업체명, 카테고리, 거리, 가중 별점, 인증 리뷰 수, 주소, 영업시간, 전화, 대표 메뉴, 리뷰 탭, 리뷰 작성 CTA를 포함한다.
- 카드 반경은 14~26px 범위의 iOS식 둥근 모서리를 사용한다.
- 정보는 카드 중첩보다 구분선과 섹션 간격으로 나눈다.

## 컴포넌트 규칙

### 지도 홈

- 지도 영역이 항상 화면 대부분을 차지해야 한다.
- 업체 마커에는 업종과 가중 별점을 표시한다.
- 선택된 마커는 네이버 그린 계열로 강조한다.
- 현위치, 확대, 축소 같은 지도 도구는 작은 floating control로 둔다.

### 검색

- 검색창은 지도 상단에 떠 있는 둥근 시트 형태로 배치한다.
- placeholder는 업체명/업종 검색 의도를 명확히 한다.
- 카테고리 필터는 가로 스크롤 칩으로 제공한다.

### 업체 상세 시트

- 네이버지도처럼 업체 기본 정보를 먼저 보여준다.
- 리뷰 작성 버튼은 상단에 명확하게 둔다.
- 길찾기, 전화, 저장, 공유는 빠른 작업으로 제공한다.
- 예약 CTA를 기본 배치하지 않는다.

### 리뷰

- 모든 집계 리뷰는 영수증 인증 리뷰로 전제한다.
- `좋았어요(4~5점)`와 `아쉬워요(1~3점)` 탭으로 나눈다.
- 리뷰 카드에는 인증 배지, 별점, 도움 수, 작성 시점, 본문, 작성자 표시를 포함한다.
- 좋아요 가중치는 작성 후 90일 동안만 반영된다는 보조 문구를 둔다.

### 리뷰 작성

- `리뷰 쓰기`를 누르면 영수증 업로드 안내가 먼저 보여야 한다.
- OCR 인증 전 별점/본문은 임시 입력 UI로만 보이고, 실제 저장은 인증 후 가능하다는 흐름을 유지한다.
- 실패 상태는 `재촬영하기`처럼 짧은 행동 문구를 사용한다.

## 화면 우선순위

1. 지도 홈: 네이버지도형 지도, 검색, 카테고리, 업체 마커
2. 업체 상세 시트: 식당 정보, 대표 메뉴, 가중 별점, 인증 리뷰
3. 리뷰 작성: 영수증 업로드, OCR 검증, 별점/본문 입력

## 피해야 할 것

- 예약 서비스를 메인처럼 보이게 만드는 구성
- 지도보다 목록이나 설명 문구가 먼저 보이는 구성
- 맛집 광고처럼 과한 이미지와 장식
- 인증/비인증 리뷰 상태가 흐릿한 UI
- iOS 스타일을 해치는 강한 테두리, 과한 그림자, 복잡한 색상
