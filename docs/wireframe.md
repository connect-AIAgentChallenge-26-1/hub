# 잔소리봇 와이어프레임

> 현재 React 앱의 실제 화면과 사용자 이동을 기준으로 정리한 문서입니다.
> 세부 스타일과 데이터 계약보다 각 화면의 목적, 주요 요소와 전환 조건을 설명합니다.

## 화면 목록 개요

| # | 화면 | 경로·표시 방식 | 역할 |
| --- | --- | --- | --- |
| 1 | Landing | `/landing` | 서비스 소개와 첫 진입 |
| 2 | Register | `/register` | 할 일과 예상 회피 이유 등록 |
| 3 | Home | `/home` | 현재 상태와 할 일 관리 |
| 4 | Nudge Modal | Home 위 dialog | Lv1~Lv4 개입과 첫 행동 제안 |
| 5 | Focus Mode | Home 위 overlay | 집중 시간 기록과 작업 종료 |
| 6 | Completion | Focus 내부 완료 단계 | 완료 결과와 피드백 확인 |
| 7 | History | `/history` | 완료 기록과 최근 실행 추이 확인 |

Nudge Modal, Focus Mode와 Completion은 별도 라우트가 아닙니다. Home 안에서 현재
상태에 따라 표시되는 흐름이며, Landing에서는 공통 Navbar 대신 전용 top bar를 사용합니다.

## 전체 사용자 흐름

```text
Landing
→ Register
→ Home
→ Nudge Modal
→ Focus Mode
→ Completion
→ History
```

Home에서는 Nudge를 거치지 않고 대표 할 일이나 active TaskCard의 시작 버튼으로
Focus에 직접 진입할 수도 있습니다. Focus에서 멈추면 Home으로 돌아갑니다.

---

## 1. Landing

**목적**

처음 방문한 사용자가 잔소리봇이 누구를 위한 서비스이며, 회피 이유를 어떻게
첫 행동과 완료로 연결하는지 이해하도록 돕습니다.

**주요 요소**

- Landing 전용 top bar와 서비스명
- 가치 제안, 설명과 `첫 행동 시작하기` CTA
- 시작이 어려운 이유와 해결 흐름
- Lv1~Lv4 개입 단계
- Shared Journey 소개와 마지막 CTA

**핵심 행동과 이동**

- 시작 CTA를 선택하면 `/register`로 이동합니다.
- `/`로 접속해도 `/landing`으로 이동합니다.

---

## 2. Register

**목적**

개입과 첫 행동 제안에 필요한 최소 정보를 한 개의 폼에서 등록합니다.

**주요 요소**

- 제목과 할 일 유형
- 선택 입력인 시작 예정 시간
- 숫자로 입력하는 마감까지 D-day
- 예상되는 회피 이유와 `기타` 선택 시 직접 입력
- 제출 오류, 등록 중 상태와 `할 일 등록하기` 버튼
- 데스크톱에서만 보이는 안내 캐릭터 영역

**핵심 행동과 이동**

- 시작 예정 시간을 비우면 현재 시각부터 시작하는 할 일로 등록합니다.
- 제목이나 D-day가 유효하지 않으면 해당 입력 가까이에 오류를 표시하고 제출하지 않습니다.
- 등록에 성공하면 `/home`으로 이동합니다.
- 등록에 실패하면 입력값을 유지하고 다시 제출할 수 있습니다.

---

## 3. Home

**목적**

현재 해야 할 일과 오늘의 실행 상태를 한 화면에서 확인하고, 직접 시작하거나
잔소리봇의 개입에 응답하는 중심 화면입니다.

**주요 요소**

- 페이지 제목과 `+ 새 할 일` 링크
- 진행 중, 마감 임박, 오늘 완료, 연속 완료 Summary
- 대표 active 할 일을 보여 주는 Journey Hero
- 진행 중, 시작 예정, 완료한 할 일 섹션
- 상태·레벨·마감·회피 이유·다음 알림 정보를 정리한 TaskCard
- 완료 기록 3개 기본 표시와 펼치기·접기
- Task가 없을 때 Journey 빈 상태와 등록 EmptyState

**핵심 행동과 이동**

- `+ 새 할 일` 또는 EmptyState CTA를 선택하면 `/register`로 이동합니다.
- Journey Hero와 active TaskCard의 시작 버튼은 Focus Mode로 직접 진입합니다.
- waiting Task는 시작 예정 시각이 지나면 서버 이벤트를 통해 active로 전환됩니다.
- 할 일을 삭제할 수 있으며, 완료한 할 일도 기존 목록 순서 안에서 관리합니다.
- 열린 Home의 브라우저 타이머가 active Task의 다음 개입 시각을 계산합니다.
- 개입 시각이 되면 Nudge Modal을 표시합니다. Focus 중에는 다른 Nudge를 띄우지 않습니다.

현재 `nextNudgeAt`은 브라우저 상태이며 서버에 영속화되지 않습니다. 따라서 Home을
닫은 뒤에도 서버가 예약 시각을 독립적으로 처리하는 구조는 아직 구현되지 않았습니다.

---

## 4. Nudge Modal

**목적**

사용자가 계속 시작하지 못할 때 현재 개입 레벨에 맞는 메시지와 실행 가능한
첫 행동을 보여 줍니다.

**주요 요소**

- 잔소리봇 이름, 자동 닫힘 시간, 닫기 버튼
- Lv1~Lv4 Badge와 단계별 상태 문구
- 레벨별 캐릭터와 개입 메시지
- Lv1·Lv3에서 필요한 경우 표시되는 회피 이유 재확인
- Lv2의 추가 입력 영역
- Lv2·Lv3의 Gemini 첫 행동 또는 rule-based fallback
- 현재 제안에 맞는 시작 CTA

**핵심 행동과 이동**

- 시작 CTA를 선택하면 화면에 표시된 첫 행동, 진입 레벨과 생성 출처를 유지한 채
  Focus Mode로 전환합니다.
- 닫기 버튼을 선택하거나 자동 닫힘 시간이 끝나면 Home으로 돌아가 다음 개입을 예약합니다.
- Lv3에서 회피 이유 재확인이 필요한 동안에는 저장과 첫 행동 생성을 완료한 뒤 시작할 수 있습니다.
- Gemini 호출이 실패해도 규칙 기반 첫 행동으로 전환해 흐름을 유지합니다.

---

## 5. Focus Mode

**목적**

직접 시작하거나 Nudge에서 선택한 행동에 집중하고 실제 경과 시간을 기록합니다.

**주요 요소**

- 현재 할 일과, 있는 경우 제안받은 첫 행동
- 진입 당시 레벨에 대응하는 Shared Journey 배경과 Walking 캐릭터
- 경과 시간 타이머
- `멈추기`와 `완료` 버튼
- 저장 실패 시 다시 시도할 수 있는 오류 표시

**핵심 행동과 이동**

- `멈추기`는 일시정지가 아니라 현재 Focus 세션을 종료하고 Home으로 돌아가는 동작입니다.
- `완료`가 성공하면 같은 overlay 안에서 Completion 단계로 전환합니다.
- 완료·멈추기 요청 중에는 중복 요청을 막습니다.
- 진행 중 세션은 sessionStorage에 저장되어 유효한 경우 새로고침 후 복구됩니다.

---

## 6. Completion

**목적**

완료 결과를 확인하고 이번 개입 경험에 대한 선택적 피드백을 남기도록 합니다.

**주요 요소**

- 완료 캐릭터와 축하 메시지
- 완료한 할 일, 첫 행동, 집중 시간과 진입 레벨 요약
- `도움됐어요`와 `아쉬웠어요` 피드백
- 피드백 저장 상태
- `홈으로`와 `기록 보기` 이동 버튼

**핵심 행동과 이동**

- 피드백은 선택 사항이며 선택해도 화면이 자동으로 닫히지 않습니다.
- `홈으로`를 선택하면 overlay를 닫고 갱신된 Home으로 돌아갑니다.
- `기록 보기`를 선택하면 `/history`로 이동합니다.
- 저장된 피드백은 현재 다음 개입에 자동 반영되지 않습니다.

---

## 7. History

**목적**

완료 기록과 최근 실행 패턴을 리스트 또는 캘린더에서 돌아봅니다.

**주요 요소**

- 전체 완료 개수
- 리스트·캘린더 전환 탭
- 이번 주 완료, 집중 시간, 평균 개입 진입 레벨, 연속 완료 Summary
- 오늘을 포함한 최근 7일 완료 추이
- 리스트의 완료 시각, 집중 시간, 진입 레벨과 조건부 첫 행동·회피 이유
- 캘린더의 월 이동, 날짜별 Task와 선택 날짜 상세
- 기록이 없을 때 등록으로 연결하는 EmptyState

**핵심 행동과 이동**

- 탭을 선택하면 같은 `/history` 안에서 리스트와 캘린더를 전환합니다.
- 기록이 많으면 리스트를 펼치거나 다시 접을 수 있습니다.
- 캘린더 날짜를 선택하면 해당 날짜의 Task를 같은 화면에서 확인합니다.
- 공통 Navbar를 통해 Home이나 Register로 이동합니다.

---

## 공통 요소

- **Navbar**: `/landing`을 제외한 화면에 표시합니다. 얼굴 로고와 서비스명,
  Home·할 일 등록·History 링크, Web Push 상태에 따른 알림 버튼을 제공합니다.
- **Shared Journey**: Home Hero와 Focus에서 Lv0~Lv4 캐릭터·날씨 배경을 사용하고,
  Completion에서 완료 경험을 이어 갑니다. 시간대별 테마와 이동 애니메이션은 없습니다.
- **Overlay 우선순위**: Focus가 열려 있는 동안 Nudge Modal을 표시하지 않습니다.
- **반응형**: 데스크톱·태블릿·모바일에서 같은 기능과 정보 순서를 유지하며,
  좁은 화면에서는 카드와 입력을 한 열로 배치합니다.
