# Later 후속 백로그

현재 운영 버전에 완료된 작업은 [`checklist.md`](checklist.md)를 참고합니다. 아래는
실제 미구현 항목만 남긴 백로그입니다.

## P0 — 공개 서비스 전 필수

- [ ] 인증과 사용자별 `owner_id` 도입
- [ ] Supabase RLS 및 Storage 소유권 정책 적용
- [ ] 기존 공용 데이터의 사용자별 migration 계획 수립
- [ ] AI가 실제 원문을 확보했는지 기록하는 분석 provenance 추가
- [ ] 캡션만 확보한 Instagram 항목을 `캡션 요약`으로 구분
- [ ] 원문 근거가 부족하면 추측 요약 대신 명시적 제한 상태 표시

## P1 — 재발견 경험

- [ ] 사용자 설정 기반 리마인더 일정과 웹 푸시
- [ ] 알림 권한 거부·재설정·중복 발송 방지
- [ ] 시맨틱 검색과 관련 콘텐츠 추천
- [ ] 저장 이유 또는 개인 메모
- [ ] 모바일 공유 시트와 Apple 단축어

- [ ] Playwright 핵심 흐름 E2E

- [ ] 접근성 자동 검사
- [ ] 플랫폼별 원문 접근 가능 범위 모니터링
- [ ] 사용자 업로드 영상 분석
