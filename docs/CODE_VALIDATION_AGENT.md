# 코드 검증 Agent

`.codex/agents/code-validator.toml`의 읽기 전용 Agent는 구현 결과를 수정하지 않고
심각도순으로 검토합니다. 자동 테스트와 사람의 최종 판단을 대체하지 않습니다.

## 요청 예시

```text
code_validator Agent로 현재 diff의 API, AI 요약 근거, 보안과 테스트 누락을 검토해줘.
```

## 검토 우선순위

1. 데이터 손실, 인증·권한과 비밀정보 노출
2. SSRF, 파일 업로드, 외부 API와 AI 출력 검증
3. 실제 원문 없이 생성한 요약의 과장·환각
4. 저장·검색·아카이브·복원 회귀
5. 접근성, 실패·빈 상태와 테스트 누락
6. 문서와 운영 구조의 불일치

## 결과 형식

- 심각도와 사용자 영향
- 재현 근거와 정확한 파일 위치
- 실행한 검사 및 결과
- 수정 권고
- 발견 사항이 없을 때 남은 위험

현재 Later에서는 Instagram 같은 플랫폼의 공개 메타데이터와 실제 영상 원문을 구분하고,
Vercel same-origin API 구조와 인증·RLS 미구현 상태가 정확히 문서화됐는지도 확인합니다.
