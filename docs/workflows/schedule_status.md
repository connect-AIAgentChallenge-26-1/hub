# Schedule Status Workflow

## Purpose

task board의 현재 값을 바탕으로 완료율, 지연 태스크, 남은 기간을 보고한다.

## Calculation Rules

- 기준일은 실행 시점의 로컬 날짜를 사용하고 답변에 표시한다.
- `complete`는 마감일과 관계없이 완료 목록에 둔다.
- `incomplete`이고 마감일이 기준일보다 전이면 `지연`, 표시는 `D+N`이다.
- `incomplete`이고 마감일이 기준일이면 `오늘 마감`, 표시는 `D-Day`다.
- `incomplete`이고 마감일이 기준일보다 뒤면 `예정`, 표시는 `D-N`이다.
- `incomplete`이고 마감일이 `TBD`면 `일정 미정`이다.
- 완료율은 `complete / 전체 태스크 * 100`이며 소수 첫째 자리에서 반올림한 정수로 표시한다.
- 전체 태스크가 0개면 완료율은 `계산 불가`로 표시한다.

## Steps

1. `workspace/tasks/task_board.md`를 읽는다.
2. 상태와 날짜 형식이 유효하지 않은 항목을 별도 경고로 분리한다.
3. 완료, 지연, 오늘 마감, 예정, 일정 미정으로 분류한다.
4. 지연은 오래된 마감일부터, 예정은 가까운 마감일부터 정렬한다.
5. 전체 요약과 사용자가 요청한 상세 목록을 답한다.

## Output

- 기준일
- 전체, 완료, 미완료 수와 완료율
- 지연 태스크와 지연 일수
- 오늘 마감 태스크
- 예정 태스크와 남은 일수
- 일정 미정 태스크
- 유효하지 않은 데이터

## Safety Rule

이 workflow는 보고 전용이다. 상태나 마감일을 추정하거나 파일을 수정하지 않는다.
