# Project Search Workflow

## Purpose

확정 문서, 아이디어, 승인 큐, 결정 로그, 버전 기록에서 근거 있는 답변을 만든다.

## Search Order

1. `workspace/project_brief.md`
2. `workspace/document_plan.md`
3. `workspace/design/`
4. `workspace/decisions/decision_log.md`
5. `workspace/versions/version_history.md`
6. `workspace/approvals/approval_queue.md`
7. `workspace/materials/source_index.md`
8. `workspace/materials/inbox/`
9. `workspace/resources/resource_inventory.md`
10. `workspace/tasks/task_board.md`
11. `workspace/ideas/temporary_ideas.md`

## Steps

1. 질문의 핵심 키워드, 대상 문서 타입, 시점을 파악한다.
2. 관련 파일을 검색한다.
3. 확정 문서, 승인 대기 자료, 관리 정보, 미승인 아이디어를 구분한다.
4. 답변에 파일 경로와 근거를 포함한다.
5. 근거가 부족하면 추정하지 말고 부족한 점을 말한다.
6. materials 원본은 reference 또는 authoritative 상태를 표시하고 확정 설계처럼 답하지 않는다.
7. `workspace/materials/inbox/README.md`는 안내 파일이므로 프로젝트 자료에서 제외한다.

## Safety Rule

검색 요청은 문서 수정 요청이 아니다. 사용자가 별도로 변경을 요청하지 않으면 파일을 수정하지 않는다.
