# 자취달력(JachiCal) — 1단계 UI/UX 설계 산출물

> 지시서 1단계 산출물: **IA 표 · 화면정의서 · 와이어프레임 · 디자인 시스템 기초**
> 와이어프레임은 코드 기반 목업 [`wireframes.html`](wireframes.html)로 별도 제공합니다.

## 1-1. IA (정보구조) 확정

### 메뉴 트리 (하단 탭 4개 기준)

```
자취달력 (JachiCal)
├─ 🏠 홈(대시보드)        ← 앱 진입 기본 화면
│   ├─ 이번 달 예산 게이지 요약
│   ├─ 다가오는 납부 D-day 리스트
│   └─ 오늘 할 일(행정 태스크) 요약
├─ 📅 캘린더
│   ├─ 월간 뷰(납부일 마킹)
│   ├─ 날짜 상세(해당일 공과금/지출)
│   └─ 공과금 항목 등록/수정
├─ 💰 예산
│   ├─ 월 예산 설정
│   ├─ 지출 목록(수동 입력)
│   └─ 카테고리별 지출 분석
└─ 👤 마이페이지
    ├─ 공과금 항목 관리
    ├─ 알림 설정
    ├─ 자취 행정 타임라인(Should)
    └─ 계정(로그인/로그아웃)
```

### 화면 목록 · 진입/이탈 정의

| ID | 화면 | 진입 조건 | 주요 이탈 지점 |
| --- | --- | --- | --- |
| S0 | 스플래시/인증 | 앱 최초 실행, 미로그인 | 로그인 성공 → S1(온보딩) 또는 S2(홈) |
| S1 | 온보딩(공과금 등록) | 신규 가입 직후, 등록 항목 0건 | 항목 1건 이상 등록 완료 → S2(홈) / "나중에" → S2 |
| S2 | 홈(대시보드) | 로그인 완료 & 온보딩 완료 | 탭 이동, 납부 카드 탭 → S4, 게이지 탭 → S5 |
| S3 | 캘린더(월간) | 하단탭 '캘린더' | 날짜 탭 → S4, 항목 추가 → S6 |
| S4 | 날짜 상세 / 납부 체크 | 캘린더 날짜 또는 홈 납부카드 진입 | 납부 완료 체크 → 이전 화면 복귀 |
| S5 | 예산 대시보드 | 하단탭 '예산' | 지출 추가 → S7, 예산 설정 → S8 |
| S6 | 공과금 항목 등록/수정 | 온보딩/캘린더/마이페이지에서 진입 | 저장 → 진입 화면 복귀 |
| S7 | 지출 입력 | 예산 화면 '+' 버튼 | 저장 → S5 복귀 |
| S8 | 월 예산 설정 | 예산 화면 '예산 편집' | 저장 → S5 복귀 |
| S9 | 마이페이지 | 하단탭 '마이' | 각 하위 항목 진입 |
| S10 | 자취 행정 타임라인(Should) | 마이 또는 홈 '할 일' | 체크/완료 → 유지 |
| S11 | 알림 설정 | 마이페이지 | 저장 → S9 복귀 |

## 1-2. 화면/기능 정의서 (핵심 플로우 3종)

PRD의 "Why"를 실행 규칙("How/What")으로 구체화합니다.

### 플로우 A — 온보딩(공과금 항목 등록)

| 단계 | 화면 | 사용자 행동 | 시스템 규칙 (How/What) |
| --- | --- | --- | --- |
| A1 | S1 | 4개 카테고리(전기/가스/수도/관리비) 프리셋 칩 노출 | 프리셋 탭 시 항목 등록 폼(S6) 프리필 |
| A2 | S6 | 납부일(매월 N일), 예상 금액, 알림 여부 입력 | 납부일은 1~31 선택. 금액은 **선택 입력**(미입력 허용) |
| A3 | S6 | 저장 | 다음 납부일 자동 계산(오늘 이후 가장 가까운 N일), 캘린더에 마킹 생성 |
| A4 | S1 | "완료" 또는 "나중에" | 1건 이상이면 홈 진입. 0건이어도 "나중에"로 홈 진입 가능 |

**규칙:** 온보딩은 스킵 가능해야 이탈을 막는다(입력 강요 금지). 등록 0건이면 홈에서 "첫 공과금 등록하기" 유도 카드 노출.

### 플로우 B — 홈 대시보드 조회

| 구성 요소 | 표시 규칙 |
| --- | --- |
| 예산 게이지 | (이번 달 지출 합 / 월 예산) 비율. 예산 미설정 시 "예산 설정하기" CTA로 대체 |
| 다가오는 납부 | 오늘 기준 D-7 이내 미납부 항목을 D-day 오름차순 최대 5개. 없으면 "예정된 납부 없음" |
| 오늘 할 일 | 미완료 행정 태스크 상위 3개(Should. 없으면 섹션 숨김) |
| 상단 인사 | "서연님, 이번 달 3건 납부 예정이에요" 형태의 요약 문구 |

### 플로우 C — 알림 클릭 → 납부 완료 체크 (KPI 직결)

| 단계 | 화면 | 행동 | 시스템 규칙 |
| --- | --- | --- | --- |
| C1 | 푸시/알림 | 납부 예정 알림 클릭 | 해당 항목의 날짜 상세(S4)로 딥링크 |
| C2 | S4 | "납부 완료" 체크 | 해당 월 Payment 레코드 status=PAID, paidAt=now 기록 |
| C3 | S4 | (선택) 실제 납부금액 입력 | 입력 시 예산 지출에도 자동 반영 여부 토글 제공 |
| C4 | S4 | 완료 | 다음 달 납부 예정 자동 생성, 홈 '다가오는 납부'에서 제거 |

### 예외 처리 케이스

| 케이스 | 처리 규칙 |
| --- | --- |
| 납부일 미확정 항목 | 납부일 '미정'으로 저장 허용. 캘린더 마킹 없이 '미정' 섹션에 별도 표시, 알림 미발송 |
| 금액 미입력 상태 | 게이지/분석에서 해당 항목 금액 0으로 제외. 홈에는 "금액 입력하기" 힌트 노출 |
| 알림 미수신 시 fallback | 푸시 실패해도 홈 '다가오는 납부' 리스트가 1차 fallback. D-1/당일 재알림 재시도 |
| 예산 미설정 | 게이지 자리를 "예산 설정하기" CTA로 대체(빈 화면 대신) |
| 지출>예산 초과 | 게이지 100% 초과분은 빨강으로 표시, "예산 초과 +₩X" 경고 문구 |
| 네트워크 오류 | 마지막 캐시 데이터 표시 + 상단 오류 배너, 재시도 버튼 |

## 1-3. 와이어프레임 (로우파이 → 미드파이)

코드 기반 목업으로 대체합니다 → [`wireframes.html`](wireframes.html) (브라우저로 열기).
포함 화면 4종: **온보딩(S1) · 홈 대시보드(S2) · 캘린더(S3) · 예산 게이지(S5)**.
아래는 각 화면의 텍스트 레이아웃 요약입니다.

- **온보딩(S1):** 상단 진행 안내 → 카테고리 프리셋 칩 4개 → 등록된 항목 리스트 → 하단 "완료/나중에".
- **홈(S2):** 인사 헤더 → 예산 게이지 카드 → 다가오는 납부 D-day 리스트 → 오늘 할 일 → 하단 탭바.
- **캘린더(S3):** 월 네비게이션 → 요일 헤더 → 날짜 그리드(납부일 카테고리 색 점) → 선택일 상세 → '+ 항목'.
- **예산(S5):** 월 예산 게이지 → 잔여금 강조 → 카테고리별 바 → 지출 목록 → '+ 지출' FAB.

## 1-4. 디자인 시스템 기초 (디자인 토큰)

톤: **친근하고 가벼운(자취생 대상)** — 라운드 코너, 부드러운 그림자, 따뜻한 포인트 컬러.

### 컬러 토큰

| 토큰 | 값 | 용도 |
| --- | --- | --- |
| `--color-primary` | `#4F6DF5` | 주요 액션, 활성 탭, 브랜드 |
| `--color-primary-weak` | `#EEF1FE` | primary 배경/칩 |
| `--color-accent` | `#FF8A5B` | 강조 CTA, D-day 임박 |
| `--color-success` | `#12B76A` | 납부 완료, 예산 여유 |
| `--color-warning` | `#F79009` | 임박, 주의 |
| `--color-danger` | `#F04438` | 연체/예산 초과 |
| `--bill-electric` | `#FDB022` | 전기 |
| `--bill-gas` | `#F97066` | 가스 |
| `--bill-water` | `#36BFFA` | 수도 |
| `--bill-maint` | `#A48AFB` | 관리비 |
| `--text-strong` | `#1D2939` | 제목/금액 |
| `--text-default` | `#344054` | 본문 |
| `--text-weak` | `#667085` | 보조/캡션 |
| `--bg` | `#F5F6FA` | 앱 배경 |
| `--surface` | `#FFFFFF` | 카드 표면 |
| `--border` | `#EAECF0` | 구분선/테두리 |

### 타이포그래피

폰트: `Pretendard`, `-apple-system`, `system-ui`, sans-serif (한글 가독성 우선).

| 토큰 | 크기/굵기 | 용도 |
| --- | --- | --- |
| `display` | 28px / 700 | 금액·게이지 중앙 숫자 |
| `h1` | 22px / 700 | 화면 제목 |
| `h2` | 18px / 600 | 섹션 제목 |
| `body` | 15px / 400 | 본문 |
| `caption` | 13px / 400 | 보조 텍스트 |
| `label` | 12px / 600 | 칩/뱃지 라벨 |

### 공통 컴포넌트

| 컴포넌트 | 정의 |
| --- | --- |
| Button | radius 12px, 높이 48px(primary)/40px(secondary). primary=채움, secondary=테두리, ghost=텍스트 |
| Card | surface 배경, radius 16px, padding 16px, 그림자 `0 2px 8px rgba(16,24,40,.06)` |
| Gauge(예산) | 반원/막대 진행형. 잔여율에 따라 success→warning→danger 색 전환 |
| Calendar Cell | 정사각, 날짜 숫자 + 하단 카테고리 색 점(최대 4개), 오늘=primary 링 |
| Category Chip | `label` 타이포, 카테고리 색 배경 10% + 텍스트 색 100% |
| Bottom Tab | 4탭(홈/캘린더/예산/마이), 활성=primary, 비활성=text-weak |

### 간격/모서리 토큰

| 토큰 | 값 |
| --- | --- |
| `--radius-sm/md/lg` | 8px / 12px / 16px |
| `--space-1..5` | 4 / 8 / 12 / 16 / 24px |
| `--shadow-card` | `0 2px 8px rgba(16,24,40,.06)` |
