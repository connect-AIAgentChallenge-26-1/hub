# Policy 0.1.3 Corpus Diagnosis

Input analyzed:

- `policy-summary.json` generated by pipeline `0.1.3`
- `publishable-candidates.jsonl` with 1,203 auto-confirmed candidates
- `review-queue.jsonl`
- `candidate-integrity.json`

The chronology integrity guard passed, but four publication-quality defects remained.

## 1. `24:00` substring parsing

Four auto-confirmed candidates contained `04:00` produced from textual `24:00` / `24시`.
The former time regex could match the trailing `4:00` substring inside `24:00`.

Examples included:

- application deadline `2026. 2. 9. 24:00까지`;
- application period ending `4월 12일 24시까지`;
- insurance period ending `2027. 2. 28. 24:00`.

Policy.5 adds numeric boundaries and explicit end-of-day handling. A single-day
`24:00` deadline becomes `23:59` on the stated date; a date-only range ending
at `24:00` remains an inclusive all-day range.

## 2. Same-day clock-range end loss

Fifty-two auto-confirmed point events had evidence such as `14:00~17:00`, but
only the start time was retained and `normalizedEnd` was null.

Policy.5 parses same-day clock ranges as timed start/end values. This covers
colon and Korean-hour forms such as:

- `10:00 ~ 17:00`;
- `14시~15시`;
- `13시~18:10분`.

## 3. Same-day precision duplicates

Thirty-three same-notice groups contained both:

- an all-day title-derived candidate; and
- a body-derived timed candidate on the same date and event type.

Policy.5 keeps the timed candidate and removes only its less precise all-day
duplicate. Different timed actions on the same date remain separate.

## 4. Internal forwarding deadlines in the student feed

At least 78 board 720/721 candidates matched administrative workflow patterns,
including:

- `학과 : ... 교육지원과로 추천자 서류 제출`;
- `교육지원과 도착기준`;
- department-to-central-office forwarding dates.

These are not student actions. Policy.5 keeps the student's own deadline in the
student feed and demotes the later internal forwarding deadline to review with
`internal_workflow_deadline`.

## Additional corrections

- Event types now prefer the action label nearest the matched date. This reduces
  cases where `합격자 발표`, `오리엔테이션`, or `온라인 설명회 - 일 시` was
  classified from unrelated application wording elsewhere in the extraction window.
- `review-queue.jsonl` now includes publishable notices that also contain one or
  more review-only candidates. Previously those embedded review candidates were
  omitted from the queue.
